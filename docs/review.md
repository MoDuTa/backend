# backend 리뷰 규칙

[공통 협업 규칙](https://github.com/MoDuTa/.github/blob/0cbbc8c62c5b1e0bfc2eb9024738cb1073a381f7/CONTRIBUTING.md)을 따릅니다

- PR 제목은 `feat: 대여 API 추가` 형식으로 작성합니다
- 작업 중 커밋 메시지는 강제 검사하지 않으며 Squash 결과에 PR 제목을 사용합니다
- GitHub 기본 승인 1명, 최신 변경 재승인, 리뷰 대화 해결과 필수 검사 통과 후 머지합니다
- CodeRabbit은 보조 리뷰이며 사람의 승인을 대체하지 않습니다
- 별도 리뷰 승인 Actions 검사는 사용하지 않습니다

공통 규칙 PR MoDuTa/.github#1을 먼저 반영합니다. 검토 중에는 위 커밋 고정 개정본을 기준으로 하며, 기존 main의 WBS 필수 안내는 이 전환에 적용하지 않습니다
